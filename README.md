# BuySphere – E-Commerce Web Application

## Project Overview

BuySphere is an e-commerce web application that allows users to browse products, add items to a cart, and place orders. It also includes an admin dashboard for managing products, categories, customers, and orders.

## ⚙️ Setup Instructions

1. Clone the repository:

   ```bash
   git clone <your-repo-link>
   ```

2. Navigate to the project folder:

   ```bash
   cd your-project-folder
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open in browser:

   ```
   http://localhost:5173
   ```

## 🛠️ Technologies Used

* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Routing:** React Router
* **State Management:** React Hooks
* **Notifications:** react-hot-toast
* **Storage:** localStorage (for products, orders, users)


## System Flow

1. **Customer Side:**

   * Users browse products
   * View product details
   * Add items to cart
   * Proceed to checkout
   * Place orders

2. **Admin Side:**

   * Login to admin dashboard
   * Manage products (add/edit/delete)
   * Manage categories
   * View and update orders
   * Manage customers

3. **Data Handling:**

   * All data (products, orders, customers) is stored in **localStorage**
   * Changes reflect instantly across pages using event listeners

## Features

* Responsive design (mobile + desktop)
* Product filtering and search
* Cart system with quantity control
* Order management system
* Admin dashboard with analytics
* Category and customer management

## Notes

* This project uses **localStorage**, so data resets when cleared.
* No backend/database is used and PASSWORDS ARE NOT ENCRYPTED.
